資工特選 - 中山大學

發表於2025-03-01|更新於2026-08-29|特殊選才
|總字數:1.1k|閱讀時間:3分鐘|瀏覽量:|評論數:

人數 🔗

  • 錄取名額：3
  • 符合報名資格人數：70
  • 過書審進面試人數：22

時程 🔗

  • 報名：10/16 ~ 10/22
  • 面試名單：11/19
  • 面試：11/22
  • 放榜：12/11

面試前 🔗

中山面試前 3 天中央就放榜了，因為我是正取已經有學校讀了所以那天完全沒有任何壓力，就當作是去高雄一日遊，我甚至穿短褲去面試（因為高雄很熱）
感謝跟我同校的許又勻（特選生命科學系）的媽媽開車載我們去面試
面試在下午所以中午先跟 Eason、冰川、Youtong 先去吃中山學餐，那個樓層設計很酷，選擇滿多的但我點的唐揚雞便當不好吃，旁邊有山有海風景很好

面試過程 🔗

中山是分組團體面試，每組有三個人，在一間超小教室有一個 ㄇ 字型桌子，三個人分別坐在一個邊，要帶自己的電腦展示簡報，有四位教授分成兩組輪流進來聽我們個別自我介紹並現場問答，所以可以聽得到其他兩人的經歷和回覆

第一組教授 🔗

👨🏻‍🏫：教授
🤡：我
👩🏻‍💻：女特選生
👨🏻‍💻：男特選生

👩🏻‍💻：（自我介紹：科技女孩計畫、英文很強、數學建模）
👨🏻‍🏫：科技女孩計畫是什麼？
👩🏻‍💻：去美國參加夏令營、在國務院演講
👨🏻‍🏫：解釋剛剛提到的費馬最後定理如何用數學建模
👩🏻‍💻：忘記了
👨🏻‍🏫：xn+yn=znx^n + y^n = z^n 在 n>2n > 2 時沒有正整數解

🤡：（自我介紹）
👨🏻‍🏫：跟科技公司合作的那個是什麼？
🤡：在當 SCIST 總召前有舉辦過演算法+資安實體營隊，有邀請贊助 SCIST 的科技公司合作演講活動
👨🏻‍🏫：你的程式網站有什麼內容？可以 Demo 一下嗎？
🤡：（現場打開這個網站 https://4yu.dev 滑這些文章給教授看）

👨🏻‍💻：（自我介紹：APCS 4+3、資研社教學）
👨🏻‍🏫：為什麼自走車要用 DFS？有嘗試過其它算法嗎？
👨🏻‍💻：讓他探索碰到死路就換一條，沒有嘗試過別的算法

第二組教授 🔗


👩🏻‍💻：（自我介紹）
👨🏻‍🏫：有沒有程式相關經驗？
👩🏻‍💻：在數學建模時有用過 Python
👨🏻‍🏫：在國務院演講是什麼樣的活動？
👩🏻‍💻：科技少女計畫

🤡：（自我介紹）
👨🏻‍🏫：你 CPE 檢定考到專業級的感想，對 CPE 有什麼建議（這個楊教授就是負責主辦 CPE 的）
🤡：我覺得考 CPE 可以練習到程式還可以順便練習英文還不錯，賽中有記分板而不是像 APCS 那種後測很棒，建議的話是每次考試的難度浮動可以穩定平衡一點、檢定系統可以更新、希望高中生不用繳錢也能考
👨🏻‍🏫：你說你以無指導老師的身份代表學校參賽是什麼？你覺得有指導老師跟沒指導老師的差別
🤡：高中資訊學科能力競賽，沒有指導老師較考驗自學能力

👨🏻‍💻：（自我介紹）
👨🏻‍🏫：為什麽不用 BFS
👨🏻‍💻：沒嘗試過
👨🏻‍🏫：遇到障礙物能及時反應嗎
👨🏻‍💻：有在程式裡面判斷
👨🏻‍🏫：vector array 差別
👨🏻‍💻：可以改變長度

意外插曲 🔗

眾所周知，中山大學有很多猴子🐒，我去面試前的路上邊走邊吃冰 🤡，直接被一隻猴子襲擊，不只搶走我的冰還把我的右手背抓出一道傷口😡

學長幫我簡單消毒後忍痛帶傷面試完才搭捷運去大同醫院打破傷風疫苗，董油桐在旁邊一直笑我😮‍💨

面試後 🔗

打完疫苗我跟 Youtong 和 Eason 就去駁二走走逛逛，還搭了輕軌，我覺得高雄給我的感覺很 Chill，我會想住在高雄但不會想讀中山😂，晚上還去吃了一間要等超久但很頂的拉麵😋




結果 🔗

備取 4（正取 3 人、備取 7 人）遞補錄取
